# Mon cours de maths

Une page pour réviser les maths de première générale : l'élève colle son cours (texte, photo ou PDF), puis choisit une bulle.

- **Explique-moi mon cours** : explication pas à pas, exemple détaillé, pièges à éviter, points à retenir.
- **Donne-moi des exercices** : trois exercices sur le cours, avec indice et correction détaillée.

## Programme officiel

Les explications et les exercices s'appuient sur un résumé du programme de spécialité mathématiques de première générale en vigueur depuis la rentrée 2026 (arrêté du 26 février 2026, BO n° 14 du 2 avril 2026). L'élève peut aussi choisir un chapitre du programme et travailler sans coller de cours.

## Utilisation

`cours-maths.html` est le code d'un artifact Claude. Les deux bulles font appel à Claude et ne fonctionnent que lorsque la page est publiée et ouverte sur claude.ai, avec un compte connecté. Ouverte ailleurs (GitHub Pages, fichier local), la page s'affiche mais les bulles ne répondent pas.
